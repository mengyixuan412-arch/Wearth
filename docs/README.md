# 文档

代码只是结果。为什么是这个形态、为什么某个功能没做、某个数为什么这么算 ——
理由都在这三份里。

| 文档 | 是什么 |
|---|---|
| [PRD.md](PRD.md) | 产品需求。问题定义、CPW 模型怎么来的、五个评分维度各自解决什么、隐私口径 |
| [ARCHITECTURE.md](ARCHITECTURE.md) | 技术架构。免登录与云端的双模式数据层、模型调用的红线、部署 |
| [DESIGN.md](DESIGN.md) | 设计规范。色彩系统、排版尺度、组件约定，以及每个页面的布局决策 |

**只想快速了解的话读 PRD 的前三节**：问题是什么、CPW 为什么是这个公式、
评分为什么必须是规则引擎而不是模型。这三节撑起了整个产品的判断。
